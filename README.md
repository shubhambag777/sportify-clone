# 🎵 Spotify Clone

A responsive Spotify-inspired music player interface built using **HTML and CSS**.

## 🚀 Features

* Spotify-inspired user interface
* Sidebar navigation
* Recently played section
* Featured charts section
* Music player control bar
* Responsive layout
* Custom images and icons

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📁 Project Structure

```text
spotify-clone/
│
├── assets/
│   ├── images and icons
│
├── index.html
├── style.css
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.

## 📌 Project Purpose

This project was created for learning and practicing **HTML and CSS**, including layouts, Flexbox, positioning, styling, and responsive design.
